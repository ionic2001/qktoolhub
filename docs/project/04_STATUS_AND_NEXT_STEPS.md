확인일: 2026-09-10. 검토 기준: 원격 main `d950c59`(문서), 운영 코드 기준 `cbfd3a0`.

## 목표와 구현 상태

설치 없이 텍스트·이미지·PDF·환산·시간 작업을 처리하는 도구 모음이다. 현재 8개 도구와 홈·약관·개인정보 페이지를 제공한다. 한국어·영어·일본어·간체 중국어·스페인어의 55개 canonical URL을 사용한다. 독립 스티커 도구와 OCR은 출시 범위에 포함하지 않는다.

기존 README, 제품 기획서, 배포 결정 메모, 개발 인수인계 문서를 모두 읽고 App.tsx의 라우트, 이미지 편집기와 스티커 자료, SEO 생성 및 검사 코드와 대조했다. 다국어 URL은 기존 lang 쿼리 정책을 유지한다. 과거 대화의 /en/ 제안으로 변경하지 않는다.

## 이번에 이어서 진행한 작업

기존 검사가 개별 명령으로 흩어져 있어 인수인계 시 일부가 누락될 수 있었다. package.json에 기존 검사 묶음 `test:regression`과 빌드부터 순서대로 실행하는 `verify`를 추가했다. 실패하면 뒤의 검사는 실행되지 않는다. 애플리케이션 소스·언어·배포 라우팅·잠금 파일은 변경하지 않는다.

```sh
npm ci
npm run verify
```

`test:regression`을 단독 실행하려면 먼저 최신 소스로 빌드해야 한다. 두 컴퓨터에서는 `verify` 사용을 권장한다. 자동 검사는 전체 UI 회귀나 모바일 성능 측정을 대체하지 않는다.

## 미완료와 다음 우선순위

1. **스티커 작업 비교**: 다른 컴퓨터의 브랜치·커밋·미반영 파일이 아직 원격에서 확인되지 않는다. 해당 작업을 기능 브랜치로 공유한 뒤 최신 main과 비교하고 확장 범위를 확정한다. 이 컴퓨터의 과거 복사본이 다른 컴퓨터의 상태를 증명하지는 않는다.
2. **Search Console 확인**: 사이트맵 재제출은 기존 문서상 완료. 실제 URL 검사 결과, 색인 제외 사유, 노출·클릭은 계정에서 확인해야 한다. 이번 작업에서는 계정 데이터를 열람하지 않았다.
3. **모바일·도구 회귀**: 실제 기기 또는 모바일 브라우저에서 8개 도구의 입력→결과→복사/다운로드를 확인하고 성능 기준값을 수집한다. 파일 변환·이미지 내보내기·알람 권한·달력 ICS도 별도 확인 대상이다.
4. **개선 우선순위 확정**: 실제 사용·검색·성능 데이터를 모은 뒤 병목을 선정한다. 현재 빌드 용량만으로 모바일 성능 통과를 판정하지 않는다.
