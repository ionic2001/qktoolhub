## 결정 사항

- 3D 디오라마 스티커북은 QK Tool Hub와 제품·배포 주기가 달라 `ionic2001/diorama-stickerbook` 독립 저장소로 분리했다. QK Tool Hub에는 이미지 편집기 내부의 기존 스티커 기능만 유지한다.

- 단순 메타태그 증설보다 초기 HTML 내용·페이지별 검색 의도·내부 연결을 우선했다.
- 홈·도구·법적 안내 페이지를 언어별 URL로 구분했다.
- src/seo/catalog.ts를 공통 메타 데이터 진입점으로 사용한다. 기존 페이지별 SEO 훅의 중복 갱신은 제거했다.
- 새 SEO 빌드는 scripts/build-seo.mjs이다. 저장소에 남은 과거 build-*-seo 스크립트는 현재 package.json의 build에서 사용하지 않는다.
- 환율 설명에서 실시간 거래 데이터로 오해할 표현을 제거했다. 환율 계산의 전체 데이터 신뢰성 감사까지 완료한 것은 아니다.
- 파일의 브라우저 처리와 광고·분석 서비스 사용을 구분해 설명한다.
- Google 제목·설명 글자수는 고정 제한으로 표현하지 않는다.
- SEO 문서상의 초기 문제 목록은 과거 감사 기록이다. 현재 상태는 이 배포 메모와 기준 커밋을 우선한다.

## 검증 기록과 한계

최종 배포에서 빌드와 정적 SEO 검사 통과. 운영 55개 URL은 HTTP 200, 자기참조 canonical, 단일 H1, 언어 연결과 JSON-LD 검사를 통과했다. robots와 공유 이미지 정상, 없는 페이지·파일은 404 및 noindex를 확인했다.

4개 외국어 홈과 글자수 화면에서 메타·번역·설명 보완을 브라우저로 확인했다. 앞선 배포에서 글자수 샘플 계산 및 기존 단위 변환 테스트도 통과했다.

Google Search Console의 실제 색인 완료·검색 순위·Core Web Vitals·전체 도구 회귀는 별도 검증 대상이다. 사용자가 사이트맵 재제출 완료를 알렸다. 계정 데이터는 이 작업에서 직접 열람하지 않았다.
