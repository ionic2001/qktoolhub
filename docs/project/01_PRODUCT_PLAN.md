## 2. 제품 목적과 사용자

설치 없이 브라우저에서 텍스트, 파일, 이미지, 숫자, 시간 관련 작업을 수행하는 온라인 도구 모음이다. 글쓰기·과제·문서 업무 사용자, 이미지와 콘텐츠 제작 사용자, 통화·단위·시간을 비교하는 사용자를 지원한다.

핵심 사용 흐름은 홈에서 도구 찾기 → 입력·설정 → 결과 확인 → 복사 또는 다운로드다. 각 도구의 사용 안내와 관련 도구 링크를 제공한다. 광고와 방문 통계 서비스를 사용한다.

## 4. 언어와 콘텐츠 정책

한국어 기본 주소에는 lang 쿼리를 붙이지 않는다. 영어·일본어·중국어·스페인어는 각각 ?lang=en, ja, zh, es를 사용한다. ?lang=ko는 한국어 기본 주소를 canonical로 사용하는 별칭이다.

URL이 표시 언어를 결정하며 저장된 언어 선호가 해당 URL을 다른 언어로 덮어쓰지 않는다. 홈 카드·메타 설명은 같은 페이지 메타 데이터를 사용한다. 새로운 기능 설명을 추가할 때 5개 언어를 함께 갱신한다. 이번 번역 검증이 모든 도구의 모든 UI 상태에 대한 완전 번역 검수를 뜻하지는 않는다.

중국어 현재 범위는 간체다. 번체 추가는 별도 기획 사항이다. 글자수 화면의 문장·줄·언어 표기 번역, 스페인어 PDF 변환 설명, 일본어 도트 그림 명칭을 보완했다.

## 5. SEO 설계

- 초기 HTML에 페이지별 제목·설명·H1·본문·내부 링크 제공.
- www 도메인으로 canonical, Open Graph, robots, sitemap 통일.
- 5개 언어 및 x-default 상호 연결.
- WebSite·WebPage·WebApplication·BreadcrumbList와 실제 PDF FAQ에 맞는 구조화 데이터 제공.
- 1200×630 PNG 공유 이미지 제공.
- 없는 주소는 404 및 noindex로 응답.
- 홈의 언어별 응답을 위해 빌드 후 루트 index.html을 제거하고 Vercel이 언어 파일로 연결하도록 구성. 이를 임의로 되돌리면 외국어 홈의 초기 HTML이 한국어로 바뀔 수 있다.
- sitemap lastmod는 실제 콘텐츠 수정일을 신뢰성 있게 관리하기 전까지 생략한다.

## 6. 스티커 확장 기획 — 제안, 미확정

운영 편집기에는 스티커 라이브러리가 연결돼 있다. 기본 도형과 장식·표정·동물·음식 등의 자료를 사용한다. 별도 스티커 전용 URL은 없다.

다른 컴퓨터에서 개발 중인 기능을 먼저 비교한 뒤 다음을 확정한다: 편집기 내부 확장인지 독립 도구인지, 입력·출력 형식, 배경 제거 또는 AI 기능 유무, 사용자 저장 방식, 자산 출처, 다국어 지원 범위. 현재 확인하지 않은 기능은 출시된 것으로 기록하지 않는다.

완료 기준 제안: 스티커 추가·선택·이동·크기 조절과 최종 내보내기 확인, 모바일 조작 확인, 기존 이미지 편집 기능 회귀 확인, 자산 및 언어 누락 확인. 독립 URL을 추가한다면 라우트·정적 HTML·canonical·hreflang·sitemap·내부 링크를 함께 추가한다.

## 7. 다음 실행 순서

1. 두 컴퓨터의 브랜치·마지막 커밋·미반영 파일을 확보하고 스티커 변경 범위를 비교한다.
2. 같은 저장소와 기능별 작업 브랜치, 인수인계 기록을 사용한다.
3. Search Console URL 검사와 페이지 색인 제외 사유를 확인한다. 사이트맵은 사용자가 이미 재제출했다.
4. 모바일 성능과 전체 도구 기능 회귀를 측정한다. 이번 SEO 작업에서 전체 기능·전체 기기 검증을 완료한 것은 아니다.
5. 검색 노출·클릭·도구 이용 데이터를 확보한 뒤 개선 우선순위를 결정한다. 수치 목표는 기준 데이터 수집 후 확정한다.
