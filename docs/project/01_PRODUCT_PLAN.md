## 1. 제품 목적과 기준

QK Tool Hub는 설치·회원가입 없이 브라우저에서 텍스트, 이미지, PDF, 계산, 시간 관련 작업을 하는 무료 웹 도구 모음이다. 사용자는 홈에서 기능을 고르고, 파일이나 값을 입력하고, 결과를 확인해 복사 또는 다운로드한다. 도구마다 실제 지원 형식·작업 범위·제한을 해당 화면과 검색용 본문에서 설명한다.

이 문서의 현재 기능은 위 운영 코드와 공개 사이트 기준이다. 다른 컴퓨터의 미반영 작업, Search Console에서 아직 확인하지 않은 성과, 후속 연구 기능은 운영 기능으로 세지 않는다. 3D 디오라마 스티커북은 별도 제품·저장소이며 QK Tool Hub 이미지 편집기 안의 기존 스티커 기능만 이 저장소 범위다.

## 3. 홈과 사용자 안내

홈 PDF 영역의 큰 카드는 `/image-to-pdf`와 `/pdf-tools` 두 개다. 바로가기 네 개가 병합·페이지 추출·페이지 정리·선택 페이지 PNG를 각 작업 URL에 연결한다. 카드 설명은 작업 입력과 결과를 구체적으로 쓰며 옛 `/pdf-converter` 카드는 다시 넣지 않는다.

홈 하단에는 메뉴를 반복하지 않는 PDF 안내 문단이 있다. 이미지로 새 PDF를 만드는 기능과 기존 PDF의 페이지 작업을 구분하고, 지원하지 않는 암호 PDF·OCR·원문 수정, 결과 문서 확인 필요성을 설명한다. 서비스 소개는 현재 기능 목록을 반영한다. 문의는 사용 도구·브라우저·재현 방법·오류 문구를 요청하되 원본 문서를 보내도록 요구하지 않는다. 약관과 개인정보처리방침은 2026-09-16에 PDF 기능 및 처리 안내로 개정했다. 문의 메일에 사용자가 직접 파일을 첨부하면 이메일 제공업체가 처리할 수 있다.

## 4. 언어와 SEO 정책

기본 한국어 URL은 쿼리 없이 사용한다. 영어·일본어·간체 중국어·스페인어는 `?lang=en|ja|zh|es`를 사용하고 `?lang=ko`는 한국어 기본 URL을 canonical로 삼는다. URL이 표시 언어를 결정한다. 새 기능이나 정책 문구는 5개 언어의 UI·메타·초기 HTML·관련 링크에서 같이 갱신한다. 중국어의 현재 범위는 간체이며 번체는 별도 제안이다.

각 공개 URL의 첫 HTTP HTML에는 고유 title·description, H1 한 개, 읽을 수 있는 본문, 자기참조 www canonical, OG/Twitter 메타, 실제 `<a href>` 내부 링크 및 JSON-LD를 제공한다. 다국어 90개 URL에는 `hreflang` 5개와 `x-default`를 제공하고, 한국어만 있는 가이드는 존재하지 않는 번역 hreflang을 만들지 않는다. JSON-LD는 WebSite·WebPage·WebApplication·Article·CollectionPage와 BreadcrumbList 중 실제 페이지 유형에 맞춘다. robots.txt는 공개 경로를 허용하며 sitemap은 106개 index 가능한 URL을 담는다. 근거 없는 빌드 일자를 `lastmod`로 사용하지 않는다. 없는 경로는 404와 noindex로 응답한다. 빌드 뒤 root `index.html` 제거와 Vercel 언어별 재작성은 외국어 홈의 초기 HTML을 위해 유지한다.

`/pdf-converter`는 색인된 기존 URL로 유지한다. 리디렉션·sitemap 제거 여부는 Search Console의 실제 검색 의도와 유입을 확인한 뒤 결정한다. 홈과 정책 페이지의 메타 설명은 현재 PDF 도구·브라우저 처리 내용을 반영하지만 존재하지 않는 PDF 편집 기능을 넣지 않는다.

## 5. 파일 처리와 데이터 안내

텍스트·이미지·PDF 도구의 사용자 입력은 가능한 범위에서 브라우저에서 처리하고 QK Tool Hub의 저장 서버로 의도적으로 업로드하지 않는다. 페이지 메모리의 작업 내용은 새로고침·탭 종료 시 사라지지만 사용자가 다운로드한 결과와 LocalStorage의 설정·임시 텍스트는 자동 삭제되지 않는다. 환율 조회, 호스팅, GA4·Vercel Analytics, Google AdSense는 별도 외부 통신·데이터 처리가 있어 개인정보처리방침에서 구분한다. 파일명·본문·페이지 이미지를 분석 이벤트로 전송하도록 설계하지 않는다.

## 6. 검증 현황과 다음 작업

코드 `21f4b77`의 빌드·정적 SEO·가이드 근거·PDF 기능·단위·테마 검사가 통과했다. 정적 SEO 검사는 106개 URL의 메타·canonical·언어 연결·JSON-LD·링크·sitemap을 확인했고, 한국어 가이드는 Article/CollectionPage 구조화 데이터와 번역 없는 URL의 hreflang 미생성을 별도로 검사하며 PDF·글자수·단위 변환·이미지 편집·환율·세계시간·달력 도구의 관련 가이드 링크도 확인한다. PDF 검사는 가이드에서 공개한 다운로드 표본의 페이지 크기·회전값도 다시 연 뒤 확인한다. 서류 제출·스캔 PDF 가이드는 운영 사이트의 390px 뷰포트에서 페이지 전체 가로 넘침, 제목 크기, 다운로드 카드, 관련 도구 줄바꿈과 표 내부 스크롤을 확인했다. 이 검사는 전체 모바일 기기, 복잡한 PDF의 서명·양식·주석 보존, 모든 도구의 전 기능 회귀나 Search Console 색인 완료를 뜻하지 않는다.

1. Search Console에서 `/pdf-converter`와 신규 PDF URL의 색인·검색어·유입을 확인하고 기존 URL 이전 여부를 결정한다.
2. 모바일·저사양 기기에서 PDF 작업 시간·메모리·다운로드와 대형·손상·암호·서명·양식 샘플을 검수해 한도와 안내를 조정한다.
3. 현재 15개 가이드의 색인·사용 반응과 도구 이동을 확인한다. 2026-09-16에 글자수·단위·이미지 가이드 3개와 서류 제출·스캔 PDF·PDF 오류 해결 가이드 3개를 Search Console 우선 크롤링 대기열에 등록했다. 같은 날 `www` sitemap도 다시 제출했으며 Search Console의 발견 URL 수는 당시 이전 값 60·90으로 남아 있었다. 다음 처리 후 현재 106개 sitemap 반영 여부를 확인한다. 단순 요약이나 자동 대량 번역은 만들지 않는다.
4. 개별 페이지 파일·ZIP, 드래그 정리, 내용 추가·워터마크·양식·OCR는 기능·개인정보·번역·SEO 검증 후 각각 출시한다.
5. 두 컴퓨터는 원격 `main`을 기준으로 작업별 브랜치를 사용하고 완료한 변경과 검증을 인수인계 문서에 남긴다. 디오라마 스티커북은 [독립 저장소](https://github.com/ionic2001/diorama-stickerbook)에서 관리한다.
