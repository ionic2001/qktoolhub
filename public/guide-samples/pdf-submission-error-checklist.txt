[실패 지점]
□ 파일을 선택할 수 없음
□ 도구에서 파일을 읽지 못함
□ 처리 중 오류 또는 멈춤
□ 결과 파일을 열 수 없음
□ 결과는 열리지만 제출 사이트가 거부함

[입력 파일]
□ 파일 확장자와 실제 형식이 일치한다.
□ 파일 크기와 페이지 수를 확인했다.
□ 암호 입력이 필요한 PDF가 아니다.
□ 다른 PDF 뷰어에서도 정상적으로 열린다.
□ 원본 파일을 별도로 보관했다.

[페이지와 가독성]
□ 예상 페이지 수와 결과 페이지 수가 같다.
□ 첫 페이지, 마지막 페이지와 파일 경계 페이지를 열었다.
□ 페이지 순서·회전·빈 페이지를 확인했다.
□ 이름·날짜·번호·도장·서명을 확대해 읽었다.
□ 전자서명·양식·책갈피가 필요하면 결과에서 확인했다.

[환경과 재현 정보]
□ 사용한 QK Tool Hub 도구:
□ 브라우저와 기기:
□ 표시된 오류 문구:
□ 오류가 발생한 조작 순서:
□ 다운로드 목록과 기기 저장 공간을 확인했다.

[최종 제출]
□ 최종 파일명에 금지 문자나 불필요한 개인정보가 없다.
□ 최종 파일 크기·페이지 수가 제출 조건에 맞는다.
□ 제출 완료 화면, 접수번호 또는 확인 메일을 확인했다.

현재 QK Tool Hub는 기존 PDF 압축, 암호 해제, OCR, 디지털 서명 생성·검증을 제공하지 않습니다.
제출기관의 최신 안내와 담당자 확인을 최종 기준으로 사용하세요.
